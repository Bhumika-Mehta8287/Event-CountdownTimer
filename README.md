# Event Countdown Timer with Congratulations Effect

This project is a simple yet engaging countdown timer built with HTML, CSS, and JavaScript. It counts down to a specific date and time and triggers a fun congratulatory effect once the timer reaches zero. This project is perfect for showcasing how to create dynamic web elements and interactive features.

## Features
- Countdown timer that displays days, hours, minutes, and seconds.
- Customizable target date and time.
- Congratulations effect that triggers once the countdown ends.
- Smooth animations and modern UI design with a gradient background.
- Responsive design for both desktop and mobile users.

## Technologies Used
- **HTML** for structure and content.
- **CSS** for styling and animations with gradient effects.
- **JavaScript** for timer functionality and the congratulatory effect.

##Usage
The countdown timer will display the time remaining until your set event date and time.
Once the countdown hits zero, a congratulatory effect will be displayed.
